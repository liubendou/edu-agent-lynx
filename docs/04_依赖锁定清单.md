## 2. 正确 import 路径

**motion mini 入口**（~135KB 仅数值，UID §7.1）：
```ts
import { createMotionValue, spring, animate } from '@lynx-js/motion/mini';
// 导出面：createMotionValue / spring / animate / 各 easing /
// useMotionValueRef（experimental，MainThreadRef 格式）/ useMotionValueRefEvent
```

**genui A2UI**（a2ui 子路径，包名确认为 `@lynx-js/genui`）：
```ts
import { A2UI, NodeRenderer, useAction, useChecks, useDataBinding } from '@lynx-js/genui/a2ui';
import { createMessageStore, MessageProcessor } from '@lynx-js/genui/a2ui'; // 同入口
```
可用子路径：`/a2ui`（=核心，含 react+store+catalog+functions）、`/a2ui/react`（A2UI 组件）、`/a2ui/store`（消息流）、`/a2ui/catalog`（defineCatalog 等 + 内置零件 Button/Card/List…）、`/a2ui/functions`、`/a2ui/snapshot`、`/a2ui/0.9`（与 /a2ui 同 dist，显式 v0.9 协议入口）。另有 `@lynx-js/genui/a2ui/styles/theme.css`。

## 3. 关键结论

- **lynx-ui 分包可用性**：swiper / draggable / feed-list 三个分包全部存在，按分包安装（符合 ARCHITECTURE §12 "分包安装"）。主包 `@lynx-js/lynx-ui` 也已安装——它是 `@lynx-js/genui` 的 peer 依赖（>=3.133.0），且聚合全部子组件（form/list/input/sheet/button/dialog/slider/swiper/switch/popover/checkbox/sortable/draggable/feed-list 等 25 个作为其 dependencies）；M3/M4 优先用分包 import，主包仅因 genui peer 而存在。
- **haptics 存在性**：`@sigx/lynx-haptics` 0.35.0 存在（R6 "包不存在"风险不成立），peer 依赖 `@sigx/lynx-core ^0.35.0` 已随装。其 API 映射 Android Vibrator/VibrationEffect 并带 `diagnose()` 诊断；**真机振动适配仍待 M6 实测**（R6 真机部分保留）。
- **ts-fsrs 5.4.2 API 事实**（冒烟测试已断言）：`generatorParameters(0.9).w` 为 **21 个**默认权重（FSRS-6，w[0]=0.212）；`Rating`：Again=1/Hard=2/Good=3/Easy=4；`State`：New=0/Learning=1/Review=2/Relearning=3；`f.repeat(card, now)` 返回 **RecordLog**（按 Rating 键控的可迭代对象，非数组）。

## 4. 安装备注

- lynx-ui 分包 peer 声明 `@types/react@^18` 与工程 `@types/react@^19` 冲突（声明滞后，纯类型层面），安装使用了 `--legacy-peer-deps`。若总控后续需补装包，同样需带该 flag。
- npm 默认源直连可用，未换镜像。
