## 3. Android 构建路径调研结论

### 路径 A：LynxExplorer App 加载 bundle（仅调试/预览）
- 官方预构建 Android APK：GitHub Release `lynx-family/lynx` tag 4.1.0 资产 `LynxExplorer-noasan-release.apk`（https://github.com/lynx-family/lynx/releases/download/4.1.0/LynxExplorer-noasan-release.apk）
- 用法：`npm run dev` → 终端出二维码/URL → LynxExplorer 扫码或在 "Enter Card URL" 输入 bundle URL。真机与电脑需同局域网，或 `adb reverse tcp:3000 tcp:3000`
- 优点：零原生工具链，秒级预览。缺点：不是"可安装的自己的 App"，无法交付 V1
- 结论：**开发期快速调试用**，不满足交付目标

### 路径 B：自建 Android 宿主工程（★ 推荐，本项目交付路径）
- 官方参考工程：`lynx-family/integrating-lynx-demo-projects` 分支 release/4.0 的 `android/KotlinEmptyProject`（已核实源码）
- Lynx Android SDK 发布在 **Maven Central**（已核实最新 4.1.0），Gradle 仓库只需标准 `google()` + `mavenCentral()`，无需额外 Lynx 仓库，国内可用 maven.aliyun.com 镜像加速
- Maven 坐标（4.1.0）：
  - 核心：`org.lynxsdk.lynx:lynx` / `lynx-jssdk` / `lynx-trace`（4.1.0）+ `org.lynxsdk.lynx:primjs:4.1.1`
  - 服务：`lynx-service-image` / `lynx-service-log` / `lynx-service-http`（4.1.0）
  - 图片库依赖（image-service 必需）：`com.facebook.fresco:fresco:2.3.0` 及 animated-gif/webp 等；`com.squareup.okhttp3:okhttp:4.9.0`
  - 调试（建议 debug 接入）：`lynx-devtool` / `lynx-service-devtool`
- 工程配置（官方 demo 实测值）：compileSdk 34 / minSdk 24 / targetSdk 34；AGP 8.5.0；Kotlin 1.9.0；Gradle 8.7；`android.useAndroidX=true`。**无需 NDK**（SDK 为预编译 AAR）
- 集成代码要点（照抄 demo）：
  - Application：Fresco 初始化 → `LynxServiceCenter.inst().registerService(Image/Log/Http/DevTool)` → `LynxEnv.inst().init(...)` + enableLynxDebug/enableDevtool/enableLogBox
  - Activity：`LynxViewBuilder()` → `setTemplateProvider(DemoTemplateProvider)` → `build()` → `setContentView` → `renderTemplateUrl("main.lynx.bundle")`
  - Provider 从 assets 读 bundle；构建时把 `dist/main.lynx.bundle` 拷入 `app/src/main/assets/`（可写 Gradle task 自动化）

### 产出 debug APK 所需组件清单
1. JDK 17+（已有 OpenJDK 25）
2. Android SDK：cmdline-tools + platform-tools + platforms;android-34 + build-tools;34.0.0
3. Gradle 8.7（demo wrapper 自带 distributionUrl，需可访问 services.gradle.org 或腾讯镜像）
4. 无需 NDK

## 4. 遇到的问题与解决方式

| 问题 | 解决 |
|---|---|
| GitHub/nvm 安装脚本在受限网络不可靠 | 放弃 nvm，直接从 mirrors.aliyun.com/nodejs-release 下载 node-v22.23.3-linux-x64.tar.xz 解压到 ~/.local/node-v22，PATH 写入 ~/.zshrc |
| create-rspeedy 在非空目录（docs/ 已存在）触发交互 | 加 `--override` 参数非交互通过；docs/ 与模板无同名文件，未受影响（已验证完好） |
| 脚手架不自动 npm install | 手动 `npm install`，后台执行 + 轮询（默认源成功，304 顶级包，0 漏洞） |
| pkill 杀 dev server 时匹配到自身命令行导致 exit -1 | 改用 `ss -tlnp` 定位监听 3000 端口的 PID 再 kill |
| search.maven.org 查询失败 | 改用 maven.aliyun.com 镜像查 maven-metadata.xml，确认 lynx 最新 4.1.0 |

## 5. 后续 Android 构建链安装步骤（给下一个子智能体）

1. **Android cmdline-tools**：从 https://mirrors.cloud.tencent.com/AndroidSDK/ 下载 commandlinetools-linux-*.zip，解压到 ~/Android/Sdk/cmdline-tools/latest/
2. **环境变量**：`export ANDROID_HOME=~/Android/Sdk`，PATH 追加 `$ANDROID_HOME/platform-tools`（写入 ~/.zshrc）
3. **SDK 组件**：`sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"`（接受 license）
4. **宿主工程**：参照 lynx-family/integrating-lynx-demo-projects@release/4.0 的 android/KotlinEmptyProject，在 edu-agent/android/ 建 Kotlin 工程（AGP 8.5.0 / Gradle 8.7 / compileSdk 34 / minSdk 24）；Gradle 发行版走腾讯镜像 https://mirrors.cloud.tencent.com/gradle/gradle-8.7-bin.zip；Maven 仓库加阿里云镜像（maven.aliyun.com/repository/google 与 /central）
5. **bundle 接线**：Gradle task 把 ../dist/main.lynx.bundle 拷入 app/src/main/assets/（先跑 `npm run build`）
6. **验证**：`./gradlew assembleDebug` → app-debug.apk → `adb install` 真机运行
7. 开发期配合 LynxExplorer（§3 路径 A）做快速 UI 迭代
